# GitHub setup (BackEnd)

Remote: [varseeker/myassist-backend](https://github.com/varseeker/myassist-backend)

```bash
git remote -v
# origin  https://github.com/varseeker/myassist-backend.git (fetch)
# origin  https://github.com/varseeker/myassist-backend.git (push)
```

## Push pertama kali

```bash
git add .
git commit -m "Initial commit: MyAssist API"
git push -u origin main
```

## Ubah remote (jika perlu)

```bash
git remote set-url origin https://github.com/varseeker/myassist-backend.git
```
